# Boyfriend's Day Scrapbook — Anam ♡ Sayan

A local React/Vite interactive scrapbook website built from the personalized content created in ChatGPT.

## Run locally

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL Vite gives you (usually http://localhost:5173).

## Photos

The 12 real photos are already included in `public/images/`.

## Music

To enable the music button, place your chosen audio file here:

`public/music/background.mp3`

The browser will not autoplay audio until the user interacts with the page.

## Main files

- `src/main.jsx` — all pages/content/interaction
- `src/styles.css` — scrapbook design and responsive styling
- `public/images/` — the 12 photos
- `public/music/` — background music location

This is a first local prototype. You can now inspect it page-by-page and request visual/content changes before deployment.
